Domain & grid extent

Enter any positive finite domain half-span, including scientific notation. Choose Infinite to extend the grid as you pan and zoom. Choose Finite to keep a fixed domain around zero: a square for Cartesian grids or a disk for polar grids. Panning and zooming in Finite mode only change the view; edit the half-span to resize the domain.

Infinite grid spacing adapts to the view. The output maps the sampled input region. Floating-point precision and function overflow still apply at extreme scales.

Numerical conventions

Angles use radians. Logarithms, roots, and noninteger powers use principal values. Poles and detected discontinuities leave gaps; fast oscillations may exceed sampling resolution.

Animation shows (1−t)z + t f(z). The point inspector always reports the full f(z).

Navigation

Input: choose Probe or Pan, or hold Shift while dragging to pan. Arrow keys follow the selected tool. Both canvases support + / − and the scroll wheel for zoom. 0 resets the input or fits the output. Escape closes dialogs.
