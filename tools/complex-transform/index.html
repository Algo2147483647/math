Expression guide +

Write naturally

+ − * / ^ and parentheses. Multiplication can be implicit: 2z, iz, or (z+1)(z-1). Powers associate right: z^2^3 = z^8.

Constants: i, pi / π, e, tau. Angles are in radians.

A note on the picture

Logarithms, roots, and noninteger powers use principal values. Poles, overflow, and detected discontinuities leave gaps. Curves are numerical samples, so very rapid oscillations may be under-resolved.

During animation, the output shows (1−t)z + t f(z). Point values always report the full function.
