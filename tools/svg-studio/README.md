# Vectora SVG Studio

一个纯前端、零构建依赖的 SVG 编辑平台。所有数据保存在浏览器本地，不会上传。

## 运行

可以直接打开 `index.html`，或在本目录启动任意静态文件服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 功能

- 选择、移动、缩放、复制和删除矢量对象
- 矩形、椭圆、三角形、星形、直线、钢笔路径、文本和图标
- 填充、描边、透明度、圆角、旋转和图层顺序控制
- 图层显隐、锁定、重命名和拖拽排序
- 网格吸附、画布平移、缩放及适应画布
- 撤销/重做、本地自动保存和常用快捷键
- SVG 文件逐元素拆分导入（保留渐变、滤镜、CSS 与变换），SVG/PNG 导出和 SVG 源码复制
- 三套可编辑的起始模板与快速配色

## 常用快捷键

`V` 选择、`R` 矩形、`O` 椭圆、`P` 钢笔、`T` 文本、`H` 抓手；`Ctrl/Cmd + Z` 撤销，`Ctrl/Cmd + D` 创建副本，`Delete` 删除，`1` 适应画布。

顶部“导入”会将 SVG 作为新文档打开并拆分成独立图层；将 SVG 拖到画布上则会把拆分后的图层插入当前文档。
