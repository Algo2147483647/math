## Purpose  
For the input $\{y_i, \boldsymbol x_i\}_{i=1}^n, \boldsymbol x_i \in \mathbb R^{\dim}$, regression problems study the relationship between the independent variable $\boldsymbol x$ and the dependent variable $y$ by finding a function form $y = f(\boldsymbol x, \boldsymbol w)$ and minimizing the error under certain criteria.  

$$
y_i = f(\boldsymbol x_i, \boldsymbol w) + \epsilon_i
$$


- $\boldsymbol x$: independent variable
- $y$: dependent variable
- $\boldsymbol w$ : unknown parameter
- $\epsilon$: error
